# Tasks

One file per task: `<nr>-<name>.md`, numbered in order (`001-protocol-client.md`). The review of a task is
`docs/reviews/<nr>-<name>.md`. The rules are in `AGENTS.md` (Working together).

```markdown
# <nr> <title>

Author: Claude | Antigravity · Reviewer: the other · Branch: task/<nr>-<name>

## Goal
What the user gets, in one or two sentences.

## Routes
New or changed routes (routes.json), or "none".

## UI
Views, texts (all 8 languages), manual chapter if a feature changes.

## Acceptance
What must work and which tests show it.
```
