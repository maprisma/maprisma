# 069 3D map layout

Author: Antigravity · Reviewer: Claude · Branch: task/069-map-3d

## Goal
Give the AI Map a usable 3D layout with extruded category plinths, tiered 3D boxes, floating shadowed cylindrical cables, socket ports, glowing 3D light pulses and a subtle perspective stage floor, while keeping every label, click target, drag handle and zoom control crisp and pixel-accurate; allow enabling or disabling it in Settings › Map.

## Routes
None. `flutter_map_layout` gains optional boolean key `three_d` (default `true` when unset; `false` switches back to the flat 2D map) in both Python and Dart validators. Protocol unchanged.

## UI
- **Settings › Map › 3D map layout** (`ValueKey('map-3d')`): on by default; off draws the flat 2D map.
- **3D stage & plinths** (`flutter_app/lib/map_3d.dart`, `map_editor.dart`, `agent_map.dart`, `map_groups.dart`, `map_lights.dart`):
  - Subtle perspective floor grid and overhead studio lighting behind the map.
  - Category cards drawn as extruded 3D slabs (separate right and bottom wall shading, ground shadow, recessed inner tray well when unfolded, top-left specular bevel; respects `card_border` and `Corners`).
  - Column group cards and node boxes drawn as solid 3D blocks with column-tiered depth (Agents deepest), hover/selection/running elevation boost, dimmed recession and top-left rim sheen, without shifting hit-test rectangles or blurring text.
  - Connection curves drawn as floating cylindrical cables with ground drop shadows, three-pass tube shading, connector ports at box edges, and 3D shaded glowing light spheres in `MapLightLayer`.
- Texts in all 8 languages (`translations/*.json`, `flutter_app/assets/translations/*.json`) and manual (`docs/manual/manual*.html`, section `flutter-map-editor`).

## Acceptance
- `tests/test_flutter_map_editor.py` and `packages/maprisma_core/test/foundation_test.dart`: `three_d` accepted as `bool`, non-booleans rejected.
- `flutter_app/test/scan_settings_test.dart`: **Settings › Map › 3D map layout** defaults to on, toggles `three_d: false` and back to `true`.
- `flutter_app/test/map_3d_test.dart` and `flutter_app/test/map_editor_test.dart`: 3D walls/stage/cables/lights render for rounded and square corners, turn off cleanly when `three_d: false`, and preserve click, drag-to-connect, hook drag and column resize usability.
